### Основные характеристики проекта:
*   **Стек технологий** ([package.json](file:///Users/yusufbek/Documents/neurulab/package.json)): 
    *   **Framework**: Next.js 16.2.5 (App Router).
    *   **UI/Библиотеки**: React 19.2.4, Framer Motion (для плавной анимации).
    *   **Стилизация**: Tailwind CSS v4 ([globals.css](file:///Users/yusufbek/Documents/neurulab/src/app/globals.css)).
    *   **Валидация**: React Hook Form + Zod.
*   **Локализация** ([LanguageContext.tsx](file:///Users/yusufbek/Documents/neurulab/src/context/LanguageContext.tsx)): Полная поддержка двух языков — русского (`ru`) и узбекского (`uz`).
*   **Контент из Markdown**: Разделы услуг и кейсов динамически загружаются из папки `content` с помощью парсера `gray-matter` и библиотеки `remark` ([content.ts](file:///Users/yusufbek/Documents/neurulab/src/lib/content.ts)).
*   **Страницы и роутинг**:
    *   Главная страница: [page.tsx](file:///Users/yusufbek/Documents/neurulab/src/app/page.tsx) объединяет секции (Hero, Services, Cases, Process и др.).
    *   Динамические страницы кейсов: `/cases/[slug]`
    *   Динамические страницы услуг: `/services/[slug]`
*   **Интерактивность**: Форма обратной связи в секции контактов отправляет данные на сервер через Server Actions ([actions.ts](file:///Users/yusufbek/Documents/neurulab/src/app/actions.ts)).

Рендеринг динамических фильтров размытия на больших областях во время прокрутки сильно нагружает GPU и вызывает просадки FPS (тормоза).

1. **Замена фильтров размытия**: В файле [globals.css](file:///Users/yusufbek/Documents/neurulab/src/app/globals.css) полностью удалены дорогостоящие для GPU фильтры `filter: blur()`. Вместо них реализованы радиальные градиенты (`glow-green` и `glow-cyan`), которые имитируют мягкое размытие на уровне самого градиента.
